# UniMeal

برنامه‌ی اندروید برای رزرو خودکار ناهار و شام در سامد دانشگاه ارومیه تا رزرو غذا هیچ‌وقت فراموش نشود.

«شروع» را می‌زنید؛ برنامه وارد می‌شود، هفته را می‌خواند، ناهار و شام‌های رزرو‌نشده را از سلف **تاک دامپزشکی** رزرو می‌کند، به هفته‌ی بعد می‌رود و تا وقتی هر چه منتشر شده رزرو شود (یا «توقف» را بزنید) تکرار می‌کند. اگر غذا تمام شده باشد یا اعتبار کم باشد فقط اعلان می‌دهد؛ سلف دیگری انتخاب نمی‌کند و هیچ رزروی را لغو نمی‌کند.

- «فقط پیش‌نمایش» به‌صورت پیش‌فرض روشن است: اولین اجرا فقط می‌گوید چه چیزی را رزرو می‌کرد.
- «منتظر منوی هفته‌ی بعد بمان» هر ۴۰ تا ۷۰ ثانیه (تا ۱۲ ساعت) بررسی می‌کند تا هفته‌ی بعد باز شود.
- سقف هزینه‌ی اختیاری برای هر اجرا.

## حریم خصوصی و امنیت
- شماره دانشجویی و رمز فقط روی همین گوشی و رمزگذاری‌شده (AES-256-GCM، کلید در Keystore) ذخیره می‌شوند و فقط با HTTPS به `nds.urmia.ac.ir` فرستاده می‌شوند.
- اگر گواهی امنیتی معتبر نباشد برنامه متوقف می‌شود و چیزی نمی‌فرستد.
- بدون سرور، بدون آمار، بدون تبلیغ. پشتیبان‌گیری خاموش است.
- رمز اشتباه فوراً اجرا را متوقف می‌کند (تلاش‌های تکراری کپچا یا قفل حساب می‌آورد).
- اگر رمز سامد را جایی فرستاده‌اید، آن را عوض کنید.

غیررسمی و بدون وابستگی به دانشگاه؛ مسئولیت استفاده با خودتان است.
