# UniMeal برای اندروید

**دیگر رزرو غذا را فراموش نکنید: UniMeal ناهار و شام شما را در سماد رزرو می‌کند.**

دکمه‌ی **شروع** را می‌زنید. برنامه وارد سماد (دانشگاه ارومیه) می‌شود، هفته را می‌خواند، ناهار و شام‌های رزرو‌نشده را در سلف *تاک دامپزشکی* رزرو می‌کند، به هفته‌ی بعد می‌رود و تا وقتی همه‌ی منوی منتشرشده رزرو شود (یا **توقف** را بزنید) ادامه می‌دهد. اگر غذا تمام شده باشد یا اعتبار کم باشد فقط خبر می‌دهد؛ سلف دیگری انتخاب نمی‌کند و هیچ رزروی را لغو نمی‌کند.

## امکانات

- **پیش‌نمایش** (پیش‌فرض روشن): بار اول فقط می‌گوید چه چیزی را رزرو می‌کرد، با یک دکمه برای رزرو واقعی.
- **انتظار برای منوی هفته‌ی بعد**: هر ۴۵ ثانیه تا ۳ دقیقه (به انتخاب شما) بررسی می‌کند و وقتی منو آمد رزرو و متوقف می‌شود.
- **یادآور هفتگی** با روز و ساعت دلخواه (بعد از ریبوت هم کار می‌کند).
- **آگاه از اینترنت**: بدون اینترنت منتظر می‌ماند و با وصل شدن ادامه می‌دهد.
- **چند حساب**: اول حساب خودتان، بعد دوستان؛ فقط با زدن «ذخیره» ذخیره می‌شود.
- **باز کردن سماد** با حساب پیش‌فرض، داخل خود برنامه.
- **سقف خرج** برای هر اجرا، **تب گزارش** (بدون رمز)، **تم تیره**، فارسی و انگلیسی، کشیدن بین تب‌ها و انیمیشن‌ها.
- **بررسی نسخه‌ی جدید**: تنظیمات ← «بررسی نسخه‌ی جدید» فقط وقتی دکمه را می‌زنید از GitHub می‌پرسد و صفحه یا APK را باز می‌کند.

## نصب

1. فایل `UniMeal-vX.Y.Z.apk` را از [آخرین نسخه](https://github.com/Mrzzan05/UniMeal-Android/releases/latest) دانلود کنید.
2. بازش کنید و اگر اندروید خواست، اجازه‌ی نصب بدهید.
3. برنامه ← **حساب‌ها** ← شماره‌ی دانشجویی و رمز ← **ذخیره**.
4. در **خانه** «شروع» را بزنید؛ وقتی از فهرست راضی بودید «فقط پیش‌نمایش» را خاموش کنید.

برای به‌روزرسانی APK جدید را روی قبلی نصب کنید؛ تنظیمات حفظ می‌شود.

## حریم خصوصی و امنیت

- شماره‌ی دانشجویی و رمز رمزنگاری می‌شوند (AES-256-GCM، کلید در Keystore اندروید) و فقط روی همین گوشی می‌مانند و فقط به `nds.urmia.ac.ir` با HTTPS فرستاده می‌شوند.
- اگر گواهی معتبر نباشد برنامه متوقف می‌شود و چیزی نمی‌فرستد.
- سرور، تبلیغ یا آمار ندارد؛ پشتیبان‌گیری غیرفعال است.
- رمز اشتباه اجرا را فوراً متوقف می‌کند.
- اگر رمز سماد را جایی فرستاده‌اید، آن را عوض کنید.

برنامه غیررسمی است و ارتباطی با دانشگاه ندارد؛ مسئولیت استفاده با خودتان است.
